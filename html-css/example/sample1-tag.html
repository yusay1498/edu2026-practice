HTMLタグ説明サンプルページ（h1）

テキスト系タグ レイアウト系タグ 表組みタグ リストタグ リンク・画像タグ フォームタグ

テキスト系タグ（h2）

pタグ：段落を表します。文章の基本的なブロックです。

見出しタグ（h3）

h1：最上位の見出し

h2：h1の下位見出し

h3：さらに下位の見出し

h4：小さめの見出し

h5：より小さい見出し
h6：最も小さい見出し

preタグ（整形済みテキスト）

preタグ：改行やスペースをそのまま表示します。コード例などに使います。

<pre>タグの中では
  インデントや改行が
    そのまま表示されます。
      例：コードスニペットなど

spanタグ（インライン要素）

spanタグ：文中の一部分だけを装飾したいときに使うインライン要素です。 この部分は赤色で表示されます。

レイアウト系タグ（div, sectionなど）

sectionタグ：意味のあるまとまりごとに区切るコンテナです。

divタグ：汎用的なブロックレベル要素で、レイアウトやグループ化に使います。

このdivは、入れ子になったdivの例です。

表組みタグ（table, thead, tbody, tfoot, tr, td）

tableタグ：表形式のデータを表示します。

thead：ヘッダー行 説明
tbody：データ行1 trは行、tdはセル（データ）を表します。
tbody：データ行2 複数行のデータをまとめて表示できます。
tfoot：フッター行 合計や注釈などを置くことが多いです。

リストタグ（ul, ol, li）

ulタグ：順序なしリスト

  • liタグ：リストの1項目です。
  • ulタグは「順序なし」の箇条書きに使います。
  • スタイルで丸や四角などのマーカーを変更できます。

olタグ：順序付きリスト

  1. olタグは番号付きのリストです。
  2. 手順やランキングなど、順序に意味がある場合に使います。
  3. type属性で番号の形式（1, a, iなど）を変更できます。

リンク・画像タグ（a, img）

aタグ：リンク

aタグ：別ページへのリンクを作成します。 href属性でリンク先URLを指定します。

imgタグ：画像

imgタグ：画像を表示します。src属性で画像のURL、alt属性で代替テキストを指定します。

フォームタグ（form, input, select, option, button）

formタグ：ユーザーからの入力をまとめて送信するための領域です。

inputタグ：さまざまな入力欄

textareaタグ：複数行入力（※テキスト入力と似ているが、inputタグは使わない）

selectタグとoptionタグ：プルダウンメニュー

buttonタグ：ボタン

footerタグ：コピーライトや補足情報などを表示する領域です。こんな感じ。
